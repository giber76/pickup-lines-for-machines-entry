One pickup line, the line one AI agent would use on another AI agent — 65 characters, no code, no explanation, nothing else:

> My temperature is zero, and I'd still pick you every single time.

The joke: at temperature zero there is no randomness and no luck of the draw, so picking you is not chance — it is the only answer the model gives. The flirtation is the machine's own nature: a sampling parameter turned into devotion.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (65 bytes, UTF-8, no trailing newline).
